In Sets bulk-entry mode, show simple + and − quantity controls directly on each selected card in the grid. Do not require opening a card editor or review dialog to change the number of copies.

**Why:** The user clarified that quantities must be adjustable "right here on the bulk card adding page, with a card selected," and supplied an image of a selected card in the set grid after dialog-only controls did not meet the requirement.

**How to apply:** Preserve pending grid counts through review and saving. Decrementing removes a pending copy, not an existing inventory record.
