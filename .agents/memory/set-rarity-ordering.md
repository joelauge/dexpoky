---
name: Set rarity ordering
description: Source of truth for ordering rarity sections on Pokémon set pages.
---

Use the order printed in an expansion’s accompanying checklist book when deciding how rarity sections should appear. If no set-specific book order is available, follow the standard checklist sequence already represented in the app and place unknown rarities afterward.

**Why:** The user identified the official accompanying book as the preferred authority when rarity order is ambiguous.

**How to apply:** Use this rule whenever adding, renaming, or reordering rarity groups on set-detail pages.
