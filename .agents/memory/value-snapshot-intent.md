---
name: Card lookup snapshot intent
description: User-selected scope for saving compared platform values and the limits of sold-price evidence.
---

Card Lookup saves the user's chosen value for today only. Do not turn it into a persistent pricing-source rule or change existing future refresh behavior without a new request.

**Why:** The user explicitly selected “Save today’s value only,” rather than a recurring pricing rule.

**How to apply:** Keep price comparisons advisory until the owner confirms one source or a compatible average for a specific owned copy. Explain that future normal refreshes can replace the snapshot.

Do not present mirrored TCGPlayer feeds as separate platforms, or count unverified eBay sold-listing medians as exact-printing prices.

**Why:** The connected catalog feeds can represent the same market, while the sold-listing scraper cannot prove finish and condition for each sale. An average of those feeds would imply independent, compatible evidence that is not available.

**How to apply:** Keep native currencies and dates visible; average distinct platforms only after currency and finish compatibility pass. Allow eBay into saved values only if later work establishes verified matching evidence.
